# 개발 현황 (2025-08-31)

## 주요 수정 사항

- **UI 표시 로직 개선 및 버그 수정**

### 1. 모니터링 현황 표시 로직 수정

- **종목명 N/A 표시 문제 해결**
  - **원인**: `monitoring_stocks` 테이블에만 종목이 있고, `stocks` 테이블에 상세 정보가 없어 JOIN 시 종목명을 가져오지 못하는 문제.
  - **조치**: DB를 직접 수정하는 대신, `stocks` 테이블 조회 실패 시 `monitoring_stocks` 테이블에 저장된 종목명을 대신 사용하도록 조회 로직 수정. (`core/db_auto_trading_handler.py`)

- **보유 종목의 전략명 'UNKNOWN' 표시 문제 해결**
  - **원인**: 보유 종목의 전략명을 찾을 때 'ACTIVE' 상태의 모니터링 기록만 조회하여, 이미 완료/제거된 종목의 전략을 찾지 못함.
  - **조치**: 'ACTIVE' 기록이 없을 경우, 해당 종목의 가장 최근 모니터링 기록을 모두 조회하여 전략명을 가져오도록 로직 개선. 기록이 없으면 '직접매수'로 표시. (`core/db_auto_trading_handler.py`)

- **손절가 N/A 표시 문제 해결**
  - **원인**: 감시 목록 추가 시, DB에 손절가가 저장되지 않는 경우가 있어 조회 시 'N/A'로 표시됨.
  - **조치**: UI 테이블 표시 단계에서 손절가 데이터가 없을 경우, 현재가를 기준으로 즉석에서 손절가를 계산하여 보여주도록 로직 추가. (`core/db_auto_trading_handler.py`)

### 2. UI 테이블 정렬 깨짐 문제 수정

- **원인**: '삼성바이오로직스' 같은 긴 종목명이나, 100만원이 넘는 가격이 표시될 때 컬럼 너비가 부족하여 테이블 전체의 줄이 깨지는 문제 발생.
- **조치**: `HTS 보유 종목` 및 `전략 추출 감시 종목` 테이블의 컬럼 너비를 전반적으로 확장하여, 내용 길이에 상관없이 깨끗하게 표시되도록 수정. (`core/db_auto_trading_handler.py`)

### 3. 코드 품질 개선

- **중복 함수 제거**: `core/db_auto_trading_handler.py` 내부에 중복으로 정의되어 있던 `_get_holding_strategy_name` 함수를 찾아 사용하지 않는 버전을 삭제하여 코드의 잠재적 오류 가능성을 줄이고 가독성을 향상함.
