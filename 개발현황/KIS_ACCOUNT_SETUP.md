# KIS 계좌번호 설정 가이드

자동매매 기능을 사용하려면 한국투자증권 계좌번호를 설정해야 합니다.

## 설정 방법

1. `.env` 파일을 열어주세요
2. 다음 줄을 추가하세요:

```
KIS_ACCOUNT_NUMBER="YOUR_ACCOUNT_NUMBER"
```

## 계좌번호 형식

- **실계좌**: 8자리-01 (예: 12345678-01)
- **모의계좌**: 8자리-01 (예: 50068832-01)

## 중요 주의사항

⚠️ **실계좌 사용 시**
- 반드시 소액으로 먼저 테스트해보세요
- 자동매매는 예상치 못한 손실을 발생시킬 수 있습니다
- 시장 상황에 따라 즉시 중단할 수 있도록 준비하세요

💡 **권장사항**
- 처음에는 모의투자 계좌로 테스트하세요
- 시스템이 안정적으로 동작하는지 확인 후 실계좌 사용을 고려하세요

## 모의투자 계좌 신청

한국투자증권 홈페이지에서 모의투자 계좌를 신청할 수 있습니다:
https://securities.koreainvestment.com/

## 문제 해결

계좌번호 설정 후에도 오류가 발생하는 경우:
1. 계좌번호에 하이픈(-)이 포함되어 있는지 확인
2. 따옴표로 계좌번호를 감싸고 있는지 확인
3. 계좌번호가 올바른 형식인지 확인

## 예시

```bash
# .env 파일 내용 예시
KIS_APP_KEY="your_app_key"
KIS_APP_SECRET="your_app_secret"
KIS_ACCOUNT_NUMBER="12345678-01"  # 이 부분을 추가
```

설정 완료 후 시스템을 재시작하면 자동매매 기능을 사용할 수 있습니다.
