✅ 1. 전략 요소 프로그래밍 정리
📌 A. 시간 프레임 구분
관점	주 차트	목적
단기	1분봉, 3분봉, 5분봉, 15분봉	타이밍 포착, 스캘핑, 뉴스 대응
중기	30분봉, 1시간봉, 일봉	추세 확인, 눌림목 진입, 상승 시그널 포착

프로그래밍 시 → 전략마다 time frame을 파라미터화하여 자동 적용 필요.

📌 B. 매수/매도 기준 신호
1) 단기 기준 (3분봉, 5분봉, 15분봉)
구분	매수 타이밍	매도 타이밍
이평선	5EMA, 20EMA 돌파	5EMA 이탈(1/3 분할매도), 역배열 발생
캔들	거래량 수반 양봉, 저점 지지 양봉	거래량 급감 음봉, 전고점 장대음봉
거래량	돌파 시 거래량 급증	고점에서 거래량 없이 음봉, 이전 양봉의 50% 이하
갭	갭상승 후 눌림목	갭상승 후 고점 매도 압력, 갭하락 후 지지 실패
추세선	하락 추세 돌파, 상승 추세 지지 반등	추세선 이탈 + 거래량 증가
2) 중기 기준 (일봉, 30분봉, 1시간봉)
구분	매수 타이밍	매도 타이밍
이평선	5일선·20일선 돌파, 골든크로스	5일선 이탈, 데드크로스
캔들	장대양봉 + 전일 고가 돌파	장대음봉, 위꼬리 음봉
거래량	박스권 상단 돌파 + 거래량 폭증	고점에서 거래량 감소
보조지표	RSI 30 반등, MACD 골든크로스, Supertrend 전환	RSI 70 이상 + 하락반전, MACD 데드크로스
패턴	이중바닥 돌파, 삼각수렴 상단 돌파	쌍봉, 헤드앤숄더
볼린저밴드	중심선 지지, 하단 반등	상단선에서 음봉, 중심선 이탈
📌 C. 보조지표 적용 기준
지표	매수 신호	매도 신호
RSI	30 이하 반등	70 이상 하락 반전
MACD	골든크로스	데드크로스
Supertrend	하락 → 상승 전환	상승 → 하락 전환
EMA	5EMA > 20EMA 돌파	5EMA < 20EMA 이탈
ATR	저 ATR + 돌파	고 ATR + 음봉 출현
볼린저밴드	하단 반등, 중심선 지지	상단선 터치 후 음봉
📌 D. 실전 적용 예시
📈 단기 트레이딩

조건: 3분봉 기준
→ 5EMA 이탈 시 1/3 매도
→ 15분봉에서 거래량 급증 양봉 이후 거래량 급감 음봉 발생 시 전량 매도

📉 중기 트레이딩

조건: 일봉 기준
→ 20일선 + 볼린저 중심선 지지, 거래량 증가 시 매수
→ RSI 70 도달 후 장대음봉, MACD 데드크로스 시 매도

✅ 2. 최신·보완할 매매 기법 제안

다음과 같은 전략은 백테스트에서 유의미한 성과가 확인되어 포함할 가치가 있습니다:

🔄 1. VWAP + 가격 반전 전략 (중단기)

조건: VWAP 하방에서 지지 or 상방 이탈 확인

적용:

VWAP 아래에서 상승 반전 + 거래량 증가 → 매수

VWAP 상방 이탈 후 재진입 실패 + 고점 → 매도

🔁 2. 다중 타임프레임 확인 전략 (MTFA)

전략 예:

5분봉 RSI 30 진입 조건이 성립

→ 상위 차트(30분 or 1시간봉)에서 상승 전환 확인 필요

⇒ 다중 조건 만족 시 매매 진행 (노이즈 제거에 효과적)

🧠 3. AI 기반 클러스터링 보조

일정 기간 종목 변동성 + 거래량 패턴 분석 → 유사 패턴 자동 분류

활용: 백테스트용 데이터 필터링에 사용 가능 (관심 종목 압축)

💥 4. 변동성 돌파 + ATR 기반 익절 전략

조건:

변동성 낮은 상태 (ATR 낮음)에서 돌파 발생 시 진입

목표가 = 진입가 + (ATR * 2)

손절 = 진입가 - (ATR * 1)

✅ 4. 백테스트 요건 정리
항목	요구사항
대상 종목	필터링된 관심종목 (시총, 거래량, 뉴스 등 고려)
