# 매매 고도화(승률·이익률) 로드맵 v1

> 목표: **승률(Win%)·기대값(Expectancy)·수익/손실비(R\:R)·슬리피지(bp)** 개선을 통해 실현손익 극대화

---

## 1) 핵심 KPI와 목표치

* **Hit Ratio(Win%)**: +5\~10%p 개선
* **Expectancy**: +0.05\~0.15/트레이드 (R단위)
* **Profit Factor**: ≥ 1.6 (스캘핑 1.4+, 스윙 1.8+)
* **Avg R\:R**: ≥ 1:1.6 (스윙 1:2.2+)
* **Slippage**: −30% 감소 (bp 기준)
* **Turnover 대비 수익률**: 개선(수수료 효율)

---

## 2) 현 구조 대비 개선 포인트(승률/이익률 중심)

### A. **신호 품질(진입) 개선**

1. **멀티전략 합의(Consensus) 진입**

   * 현재: 각 전략별 신호→진입
   * 개선: `≥2 전략 동시 충족 + MTF 컨플루언스 ≥ θ`
   * 보정: 최근 60일 전략별 **정밀도(precision)** 가중치로 투표
2. **레짐(시장 체제) 인지 진입**

   * 레짐별 온/오프: 상승장=추세추종 가중↑ / 횡보=리버전 가중↑ / 급락=관망 또는 숏(가능시)
3. **변동성/유동성 게이트**

   * ATR% 하한, 거래대금 상한/하한, 스프레드/딥스 임계 만족 시만 진입
4. **뉴스 리스크 차단**

   * 악성 키워드/감성<τ, 공시 이벤트 직후 N분 쿨다운

### B. **실행(Execution) 알파**

1. **슬리피지 캡 + 재시도/리프라이스**

   * 리밋±ε, IOC 시도→미체결 시 재호가(틱 단위) with 하드 캡(bp)
2. **VWAP/POV 참여율 기반 체결**(스윙)

   * 목표 참여율(POV)로 미끄러짐 최소화
3. **마이크로구조 시그널**(선택)

   * **체결강도, 오더북 불균형(OBI)** 로 단기 진입 타이밍 개선

### C. **청산/손익 구조 최적화**

1. **Asymmetric Exit**

   * 1차 부분익절(예: +1R 50%청산) + 트레일링(ATR·α)
2. **시간 기반 스탑(Time Stop)**

   * 목표에 미도달 상태로 N봉 정체→청산(승률 상승)
3. **변동성 확장/축소 기반 청산**

   * Keltner/BB 밴드 터치/이탈에 따른 프로시저

### D. **포지션 사이징/포트폴리오**

1. **에지·변동성 동시 반영 사이징**

   * `size ∝ p(win)*RR / vol` (실측 기대값 기반)
2. **상관/섹터 캡**

   * 동일 섹터·상관>0.7 묶음에 노출 한도
3. **연속 손실 적응형 디리스크**

   * L회 연속 손실 시 k% 사이징 축소, 레짐 재평가

## 3) 전략 세트(강화안)

### 3.1 코어 전략(진입)

* **Squeeze Momentum Pro**: 압축→확장 초기(히스토그램 -→+) + 상위TF 동행
* **EMA Ribbon Trend**: 8>21>55 정렬 + MTF 일치(15m/1h/1d)
* **Breakout+Retest**: 돌파 후 첫 되돌림 재지지 캔들(거래대금↑)
* **Mean Reversion (RSI2/BB)**: 과매도 이탈→복귀 크로스 업, 과매수 반대
* **VWAP Reclaim**: 세션 VWAP 하향 이탈 후 재안착 + 체결강도↑

### 3.2 보조 필터(게이트)

* **Liquidity Gate**: 스프레드<=x tick, top3 호가 잔량≥L
* **News Gate**: 감성<−τ 또는 중요 공시→차단/쿨다운
* **Regime Gate**: SIDEWAYS|UP|DOWN별 실행전략 스위치

### 3.3 청산 규칙(템플릿)

* **RR 템플릿 A(스캘핑)**: 0.7R 부분익절 40% → 1.5R 전량 or 시간스탑 12봉
* **RR 템플릿 B(스윙)**: 1R 30% → 2.5R 30% → 트레일 ATR(14)\*1.2

## 4) 구현 체크리스트(핵심 로직)

### 4.1 멀티전략 합의 스코어

```python
# 각 전략의 최근 precision을 가중치로 투표
score = sum(w_i * signal_i for i in strategies)  # signal_i ∈ {0,1}
precisions = rolling_precision(lookback=60d)
w_i = normalize(precisions)
consensus = score >= theta  # theta 예: 2.0
```

### 4.2 MTF 컨플루언스

```python
mtf = 0.1*s_3m + 0.2*s_15m + 0.3*s_1h + 0.4*s_1d
enter = consensus and (mtf >= mtf_min)
```

### 4.3 사이징(에지·볼 동시 반영)

```python
edge = expectancy(symbol, profile)  # 최근 30~60일 전략 기대값
vol  = atr_pct(symbol)              # 변동성
size = base_risk * clip(edge,0,edge_cap) / vol
```

### 4.4 슬리피지 캡 실행

```python
limit = anchor_price + sign * max_slip_bp * 1e-4 * anchor_price
res = place_limit(limit, ioc=True)
if not res.filled: reprice_tick()
```

### 4.5 시간 스탑 & 트레일링

```python
if bars_since_entry >= N and unrealized<τ: exit()
trail = atr(14) * alpha
stop = max(stop, price - trail)  # 롱 기준
```
