# 매매조건 분석 및 개선안

## 🔍 현재 매수가 발생하지 않는 주요 원인

### 1. **매수 조건이 너무 까다로움**
```python
# 현재 조건: 2개 이상 매수 신호 필요
if len(buy_signals) >= 2:
    return SignalType.BUY_SIGNAL
```

**문제점:**
- EMA돌파 + 거래량급증
- 지지반등 + 거래량급증 
- RSI과매도반등

이 3개 조건 중 **2개 이상**이 동시에 만족되어야 매수하는데, 이는 매우 보수적인 조건입니다.

### 2. **기술적 분석 데이터의 부정확성**
```python
# 폴백 데이터 (실제 차트 분석 없음)
'ema_5': current_price,      # 현재가로 근사
'ema_20': current_price,     # 현재가로 근사  
'rsi': 50,                   # 중립값
```

**문제점:**
- 실제 차트 데이터 분석 없이 더미 데이터 사용
- EMA 5와 20이 같으면 돌파 신호 발생 불가
- RSI가 항상 50이면 과매도/과매수 신호 없음

### 3. **거래량 분석의 문제**
```python
'volume_avg': volume * 0.8,  # 추정 평균 거래량
```

**문제점:**
- 현재 거래량의 80%를 평균으로 설정
- `volume > volume_avg * 1.5` 조건이 거의 항상 만족됨 (1 > 0.8 * 1.5 = 1.2 이므로 항상 false)

```python
async def _calculate_real_technical_indicators(self, symbol: str, price_data: List[Dict]) -> Dict:
    """실제 기술적 지표 계산"""
    if len(price_data) < 20:
        return self._create_fallback_data(symbol)
    
    df = pd.DataFrame(price_data)
    
    # 실제 EMA 계산
    ema_5 = df['close'].ewm(span=5).mean().iloc[-1]
    ema_20 = df['close'].ewm(span=20).mean().iloc[-1]
    
    # 실제 RSI 계산
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0).rolling(14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
    rs = gain / loss
    rsi = 100 - (100 / (1 + rs)).iloc[-1]
    
    # 실제 평균 거래량 계산
    volume_avg = df['volume'].rolling(20).mean().iloc[-1]
    
    return {
        'ema_5': ema_5,
        'ema_20': ema_20,
        'rsi': rsi,
        'volume_avg': volume_avg,
        # ... 기타 지표들
    }
```

### 3. **매매조건.md의 구체적 기준 적용**

```python
def _determine_trading_signal_enhanced(self, conditions: TradingCondition, stock: MonitoringStock, tech_data: Dict) -> SignalType:
    """개선된 매매 신호 판단 - 매매조건.md 기준"""
    
    buy_score = 0
    buy_reasons = []
    
    current_price = tech_data['current_price']
    ema_5 = tech_data['ema_5'] 
    ema_20 = tech_data['ema_20']
    rsi = tech_data['rsi']
    volume = tech_data['volume']
    volume_avg = tech_data['volume_avg']
    change_rate = tech_data['change_rate']
    
    # 1. 이평선 조건 (20점)
    if ema_5 > ema_20:  # 5EMA > 20EMA 돌파
        buy_score += 20
        buy_reasons.append("5EMA>20EMA")
        
        # 보너스: 이평선 수렴 후 확산
        ema_gap_ratio = (ema_5 - ema_20) / ema_20 * 100
        if 0.5 < ema_gap_ratio < 2.0:  # 수렴 후 확산 구간
            buy_score += 10
            buy_reasons.append("이평선확산")
    
    # 2. 캔들 조건 (25점)
    if change_rate > 1.0 and volume > volume_avg * 1.2:  # 거래량 동반 양봉
        buy_score += 15
        buy_reasons.append("거래량동반양봉")
        
        if change_rate > 2.0:  # 강한 양봉
            buy_score += 10
            buy_reasons.append("강한상승")
    
    if change_rate > 0.5 and rsi < 40:  # 저점 지지 양봉
        buy_score += 15
        buy_reasons.append("저점지지반등")
    
    # 3. 거래량 조건 (20점)  
    if volume > volume_avg * 1.5:  # 거래량 급증
        buy_score += 15
        buy_reasons.append("거래량급증")
        
        if volume > volume_avg * 2.0:  # 거래량 폭증
            buy_score += 5
            buy_reasons.append("거래량폭증")
    
    # 4. RSI 조건 (20점)
    if 25 < rsi < 35 and change_rate > 0:  # RSI 과매도 반등
        buy_score += 20
        buy_reasons.append("RSI과매도반등")
    elif 35 < rsi < 65:  # RSI 정상 범위
        buy_score += 5
        buy_reasons.append("RSI정상")
    
    # 5. 추세 조건 (15점)
    # 간단한 추세 판단 (3일 연속 상승/하락)
    if change_rate > 0:  # 상승일 때
        buy_score += 10
        buy_reasons.append("상승추세")
    
    # 매수 신호 판단
    if buy_score >= 60:  # 60점 이상
        self.logger.info(f"📈 {stock.symbol} 매수 신호 - 점수: {buy_score}점, 이유: {', '.join(buy_reasons)}")
        return SignalType.BUY_SIGNAL
    elif buy_score >= 40:  # 40-59점
        self.logger.info(f"⚡ {stock.symbol} 관심 - 점수: {buy_score}점, 이유: {', '.join(buy_reasons)}")
        return SignalType.WATCH
    else:
        return SignalType.HOLD
```

## ⚡ 권장 구현 순서

1. **1단계 (즉시)**: 매수 조건 완화 (`>= 2` → `>= 1`)
2. **2단계 (당일)**: 거래량 계산 로직 수정  
3. **3단계 (1-2일)**: 실제 차트 데이터 분석 구현
4. **4단계 (3-5일)**: 점수 기반 매매 시스템 구축
5. **5단계 (1주)**: 매매조건.md 전체 기준 구현
