========================================
자동 거래 시스템 스케줄 설정 가이드
========================================

📅 목표: 매일 08:30에 자동으로 거래 시스템이 실행되도록 설정

🔧 설정 방법:

1. 관리자 권한으로 PowerShell 실행
   - 시작 메뉴에서 "PowerShell" 검색
   - "Windows PowerShell"에서 우클릭 → "관리자 권한으로 실행"

2. 거래 시스템 폴더로 이동
   cd D:\trading_system

3. 스케줄러 설정 스크립트 실행
   .\setup_schedule.ps1

4. 설정 확인
   .\manage_schedule.ps1 status

📊 관리 명령어:

• 현재 상태 확인:     .\manage_schedule.ps1 status
• 스케줄 활성화:      .\manage_schedule.ps1 start
• 스케줄 비활성화:    .\manage_schedule.ps1 stop
• 수동 테스트:        .\manage_schedule.ps1 test
• 스케줄 완전 제거:   .\manage_schedule.ps1 remove

🗂️ 생성된 파일들:

• run_auto_trading.bat     - 자동 실행 배치 파일
• setup_schedule.ps1       - 스케줄러 설정 스크립트
• manage_schedule.ps1      - 스케줄 관리 스크립트
• logs/auto_trading_schedule.log - 실행 로그

⚠️ 주의사항:

1. 컴퓨터가 08:30에 켜져 있어야 합니다
2. 절전 모드에서도 깨어나서 실행됩니다
3. 사용자가 로그인되어 있어야 합니다
4. 처음 설정 후 한 번 수동 테스트 권장

🧪 테스트 방법:

1. 수동 테스트:
   .\manage_schedule.ps1 test

2. 배치 파일 직접 실행:
   .\run_auto_trading.bat

3. 로그 확인:
   type logs\auto_trading_schedule.log

✅ 설정 완료 후:
매일 08:30에 자동으로 main.py --mode auto --no-interactive가 실행됩니다.

📞 문제 발생 시:
• 로그 파일 확인: logs\trading_system.log
• 스케줄 상태 확인: .\manage_schedule.ps1 status
• 수동 실행 테스트: python main.py --mode auto --no-interactive
